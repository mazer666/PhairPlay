# dependency-allowlist.txt — the dependencies PhairPlay is allowed to ship.
#
# WHY: every dependency is a decision that somebody has to make on purpose.
#      The version catalog says WHICH version is used; this list says that
#      the dependency itself was looked at and accepted. A dependency that is
#      not listed here has not been assessed, and the gate reports it as
#      such — it does not count as "passed", because nobody took the
#      decision.
#
# FORMAT
#   <group>:<artifact>            one dependency per line
#   # <justification>             a comment that says why it is accepted
#
# The comments are the interesting part: a list without a reason is a list
# without a decision. When a dependency is removed, its line goes with it.
#
# MAINTAINED BY
#   the team owner, together with scripts/allowlists/known-vulnerabilities.txt
#

# ── AndroidX ─────────────────────────────────────────────────────────────────

androidx.core:core-ktx                         # the Kotlin extensions of the platform
androidx.datastore:datastore-preferences       # the typed settings storage
androidx.leanback:leanback                     # the TV focus management and the on-screen keyboard

org.jetbrains.kotlinx:kotlinx-coroutines-core     # the same, for the JVM test runner
