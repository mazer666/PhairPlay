# Google Play Compliance Matrix — PhairPlay

**Version:** 1.0
**Owner:** Project Manager
**Date:** 2026-11-05
**Measured on:** commit `34a166c` (branch `main`), release `v1.0.0-alpha.7`
**Applies to:** the `googletv` flavour, `com.phairplay.googletv` — the app that
is intended for the Google Play Store.

**How to read a row.** `erfüllt` means the requirement is met **and** the proof
is in the repository or in a measurement. `offen` means the requirement is not
yet met, or the proof does not exist yet. `nicht anwendbar` means the
requirement does not apply to this app — every such row names the reason.
**No row is marked "conforming" without a proof.** A row is only `erfüllt` when
the Nachweis column names a file, a command, a measured value or an official
document.

**Sources.** Only official Google sources are used:
`support.google.com/googleplay/android-developer`, `developer.android.com` and
`play.google.com/console`. Every row carries the URL and the **retrieval date
2026-11-05**.
